知识要点

  1. 1.第一性原则 = 拆到不可再拆的客观前提，再自下而上重构；核心三步是质疑假设 → 分解要素 → 从零构建。
  2. 2.产品用法可压成一问：「这个观点 / 产品要成立，最核心必须改变的底层事实是什么？」找不到底层变化，多半只是愿景或类比。
  3. 3.判断流程：抽掉口号 → 追问底层变量 → 检验变量是否真变 → 再看产品是否抓住该变化并转成可感知价值。
  4. 4.对 AI 眼镜：不问「能做哪些功能」，而问相对手机 / 手表真正由眼镜形态带来的变化（第一人称感知、always-on、低侵入提示、空间锚定、与 agent 持续连接等）。
  5. 5.与 anchoring effect 的分工：第一性管内部「凭什么成立」，锚点管外部「用户把它理解成什么」。
  6. 6.thinking model 相关笔记几乎空白，本篇实际承载了主要内容。
一句话检验：找不到必须改变的底层事实，就还不是第一性推理。

优化建议

  1. 1.删除或压缩：「一些 gpt 生成的 case」整表；其中前臂分辨率 ≈5 mm 等数字与公开人因文献冲突，削弱可信度。
  2. 2.添加可核验引用（待确认）：Posterior Analytics + SEP Aristotle’s Metaphysics；可穿戴触觉可核 Morioka、Mahns et al. 2006、Appl. Sci. 2019 DOI 10.3390/app9204329。
  3. 3.内容重构：把 2026-06-18「产品判断流程 + AI 眼镜 + 锚点关系」提成主线；开头定义压短；给 anchoring effect 补回链。
  4. 4.增量补充：给 thinking model 写几行摘要或拿掉空链；用真实 Assumption→Why→Fact→Design Choice 短例替换 GPT case；修 ModifiedTime frontmatter 规范。
